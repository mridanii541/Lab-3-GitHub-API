
# Lab 3: GitHub Collaboration & API Interaction

## Objective
To learn Git version control, GitHub repository management, and API interaction.

## Tools Used
- Git
- GitHub
- Command Prompt
- curl
- jq

## Tasks
1. Check Git installation and version.
2. Configure Git username and email.
3. Create and manage a Git repository.
4. Track changes using Git commands.
5. Interact with a public API using curl.
6. Document commands and API responses.

## Learning Outcome
Learn the basics of version control, remote repositories, and API requests.
